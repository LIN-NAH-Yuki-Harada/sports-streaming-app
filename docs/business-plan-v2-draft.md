## 1. LIN-NAH 既存事業の収益改善計画 (懸念①回答)

### 1.1 現状認識

- 主要事業内容: **「マーケティングデザインカンパニー」** として、私立学校・一般企業のデザインを、単なる制作ではなく **マーケティング視点で企画立案から制作まで一貫** して手がけてきた（学校案件・企業案件 多数）。
- 主要クライアント業種: **私立学校（教育機関）・一般企業**
- 前期+当期 約1,000万円欠損の主要因: 大きく2点。**①生成AIの普及によりデザイン制作単体の受注・収益が成立しにくくなったこと、②デザイン業特有の「受注→納品→入金」リードタイムの長さ**。昨年度は立命館中学校・高等学校の創立120周年記念誌など大型案件に注力した反動で、後続の学校案内案件（立命館中高・西武文理中学高等学校・立教新座中学高等学校・昭和鉄道高等学校 等のコンペ）が受注に至らず、**売上の谷**が発生。コンペ参加を継続するための運用コストは固定的に発生し続けるため、キャッシュフローの回復が困難となり、**代表が私財を投じて事業を継続**してきた。（※欠損 1,000 万円の数値内訳は別途確定）
- 取引先継続状況: **立命館中学校・高等学校をはじめ、私立有名校・一般企業との取引／コンペ参加の営業基盤は健在**。直近は複数校の学校案内コンペに参加するも受注に至らず、売上機会の取りこぼしが収益を圧迫している。

> **この事業環境の変化こそが、当社が新規事業 LIVE SPOtCH を立ち上げた背景**です。デザイン事業を脅かした生成AIを **「逆手に取り」、開発をほぼ全て AI で内製**することで、外注に頼らず低コストで本格的な SaaS を構築しました。すなわち、既存事業の苦境を **「AI を使いこなす力」という新規事業の競争力へ転換**しております。

> さらに LIVE SPOtCH の **月額サブスクリプション型モデルは、デザイン業の弱点であった「受注〜入金リードタイムの長さ」を構造的に解消**します（毎月の経常収益化＝安定キャッシュフロー）。本件の運転資金は、この収益構造の転換が軌道に乗るまでの **「私財依存から正常な会社運営への回復」原資**です。なお、コンペで接点を持つ私立校群（立命館・西武文理・立教新座 等、いずれも運動部を擁する）は、**LIVE SPOtCH の有力な横展開先**でもあり、既存の営業基盤を新規事業の販路へ転用できます。

#### B. 配信プロトコル TCP 化 (B 案) — 4G 環境下での画質安定の根本解決
**5月10日の試合配信で確認した課題**: WebRTC (UDP) は 4G 上り変動下で画質が不安定。BAND (NAVER) など他プラットフォームは TCP 系プロトコルで再送機構が効くため安定。

LIVE SPOtCH もこれを実現するため、**配信者ブラウザの MediaRecorder で動画チャンクを生成し、中継 server (Cloudflare Workers / Fly.io) 経由で RTMP に変換** する方式に切り替えます。

| 月コスト | +$5-20（中継 server, 約 ¥800-3,000）|
| 効果 | 4G 体育館でも 1080p / 3-5 Mbps の高画質安定配信 |
| マイルストーン | 5/15 設計完了 / 5/22 実装完了 / 5/29 実機検証 / 5/31 本番反映 |

## 5. Exit シナリオ (Appendix)

### 5.1 スポーツブル買収戦略

スポーツブル (KDDI 系・運営: ベースボール・マガジン社等が出資) は地域大会・部活配信を扱っていない。理由:
- プロカメラクルー派遣ベースで運営コストが高い
- ローカル試合の収益性が合わない

LIVE SPOtCH は **UGC (保護者撮影) でこのコスト構造を解消**。買収側メリット:
- 撮影者の負担減 (保護者が UGC として提供)
- 運営コスト大幅削減
- ユニークユーザー数の大幅 UP (ローカルスポーツは膨大な未開拓市場)

### 5.2 接触ロードマップ
- Year 1 中盤 (2026年秋): 連盟アプローチを通じてスポーツブル運営側との接点形成
- Year 2 (2027年): 本格交渉開始
- Year 3 以降: 買収提案 / 戦略提携 のいずれか

> ※本 Exit は事業継続前提の「もう一つの出口」であり、融資返済は本業 (LIVE SPOtCH サブスク) で確保いたします。
